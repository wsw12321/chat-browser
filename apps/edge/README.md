# Edge API implementation

The module exports `createWorker({ fetch?, timeouts? })` for deterministic tests and a default Worker instance for Wrangler. `GATEWAY_ORIGIN` supplies the default HTTPS Gateway, alongside an independently configured `PUBLIC_ORIGIN` and an explicit JSON `MODEL_CAPABILITIES` array. A browser can select a different Gateway using the `X-Gateway-URL` header on `/api/models` and `/api/chat`; the value is validated per request and is never forwarded upstream. Base URLs may include a proxy path or end in `/v1`. URLs with credentials, queries, fragments, local hostnames, private IP literals, or the website's own origin are rejected. The optional local HTTP exception requires `ALLOW_LOCAL_GATEWAY=true` and both the selected Gateway and website origins to be loopback addresses. Redirects remain disabled. These literal-address checks do not perform DNS resolution; production network reachability is also governed by the Workers runtime.

The protected routes perform header/origin checks, acquire one of four isolate entry permits, validate the Bearer format, apply the platform IP limiter, query `/v1/models`, and intersect the result with the reviewed capability table. A chat then acquires one of two parsing permits, counts the real request stream, decodes strict UTF-8, rejects duplicate JSON keys and excessive nesting, validates the complete conversation and normalized image structures, and rebuilds a new Responses body. Only the current Bearer authorization, content type, and accept header go upstream. Redirects are rejected. Neither a failed validation nor a timeout automatically retries generation.

The parsing permit is released before waiting for generation headers. The entry permit remains held until the response body completes, fails, or is cancelled. Both the incoming request's abort signal and the outgoing body's cancellation abort the upstream fetch and cancel its reader. Backpressure bounds the outgoing queue; each upstream event and the whole stream have independent byte limits. Each raw network chunk is counted before decoding, then decoded in at most 16 KiB slices and consumed through a one-event iterator, so a chunk with many tiny events does not create an event object array. Heartbeat comments do not reset the upstream idle timer, which continues during downstream backpressure. Text deltas are reconciled by output/content indexes with final message content. Unsupported tools terminate the stream without executing anything. Safe error events carry website and validated Gateway request IDs; raw upstream errors and unknown metadata are not forwarded.

The shared executable policy and API contract live in `packages/contracts/src`. The complete error mapping is `packages/contracts/src/errors.ts`. Image validation checks canonical Base64, PNG chunk order/CRC/non-animation/zlib framing, or JPEG markers and frame dimensions. It does not decode pixels at the edge; the browser separately decodes and re-encodes selected image files.

Run `pnpm test` for request, image, parser, timeout, permit, and cancel regressions, and `pnpm test:workers` for native workerd routing/stream/cancellation tests. The test pool pins compatibility date `2026-08-22`, matching the deployment configurations. `pnpm deploy:check` performs a dry-run only. The mock Gateway at `scripts/mock-gateway.mjs` exposes content-free counters at `/__state` for local cancellation checks; it is not a production service.

The tests prove local application behavior. Production IP limiter behavior across Cloudflare locations, worst-case isolate memory/CPU, real Gateway lease release, model capabilities, and all production data-retention settings still require deployment acceptance. Isolate counters do not establish a distributed concurrency quota. No production publication or real paid-model acceptance is implied by a passing mock test or dry-run.
